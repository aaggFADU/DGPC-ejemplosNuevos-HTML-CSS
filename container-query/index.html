Tarjetas "responsivas" con CSS @container

Sección 1

Cuando el layout general y los componentes varían según el ancho de la ventana del navegador, se usan reglas CSS @media.

Pero cuando un componente debe adaptarse al espacio disponible donde se ubica, independientemente del ancho del navegador, se lo define como contenedor con la propiedad container-type y se usan reglas CSS @container para transformar los elementos que tiene adentro.

Sección 2

Para mantener un código limpio y escalable, en este proyecto se definió una sola estructura para todas las secciones y sus tarjetas.

Al cambiar en cada sección el valor de la variable --tamanio, la misma declaración de plantilla de columnas general y la misma regla @container general se encarga de adaptar el layout automáticamente.

Además, al cambiar en cada sección el valor de las variables --fondo-ficha y --color-textos, se personalizan los colores.
