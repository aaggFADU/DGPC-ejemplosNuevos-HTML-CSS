Borde con brillo giratorio en Hover con @property

Demo interactiva de animación de variables CSS tipadas.

Tarjeta interactiva

Al pasar el mouse (hover), se activa una transición animada sobre la propiedad registrada --rotate.

Esto permite animar gradientes con fotogramas clave (keyframes) de forma nativa en CSS.
